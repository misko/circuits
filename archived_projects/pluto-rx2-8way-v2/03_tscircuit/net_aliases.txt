# net_aliases.txt — TSNAME CANONICAL, one per line. `#` starts a comment;
# `=` and `->` are also accepted as separators. Auto-discovered by the
# converter (circuit_json_to_kicad_sch.py) next to build/.
#
# WHY IT EXISTS AT ALL: tscircuit's `net.` selector cannot author a name
# starting with a digit, so a digit-leading rail is authored with an
# author-prefix `N`. The converter's canon_net then strips a single leading
# `N` THAT GUARDS A DIGIT (N5V -> 5V, N3V3 -> 3V3) and leaves a leading N
# followed by a non-digit alone (NRST, NC, NRESET).
#
# THIS BOARD HAS TWO DIGIT-LEADING RAILS AND BOTH ARE WRITTEN OUT rather than
# left to the convention. The convention would handle them, and the lines are
# still here on purpose: 03_src/rules/nets.yaml keys its netclasses on the
# CANONICAL names, and on this board a netclass miss is not cosmetic — PWR is
# `min_width: 0.4mm`, and a rail that fell to the default 0.25 mm class would
# be graded by A-AMP as a signal net. An explicit mapping cannot be silently
# wrong the way an assumed one can.
#
# NOTE THE SECOND LINE. `3V3_MOD` is NEW in v2 and is the one an assumed
# convention is most likely to get wrong, because it is the module-side half of
# a rail split by a SERIES ferrite. v1 learned this the same way with VBUS_LDO,
# which was missing from its class until a late merge and would have carried
# the whole rail at signal width.
N3V3      3V3
N3V3_MOD  3V3_MOD

# EVERY OTHER NET ON THIS BOARD STARTS WITH A LETTER AND PASSES THROUGH
# VERBATIM. Listed here as a POSITIVE STATEMENT, because the absence of a line
# and the absence of a need are not the same thing to a reader:
#
#   RF50     ANT1..ANT7, RX1_MAIN, RX1_TAP_MID, RX1_TAP, RX2_OUT
#   CTRL     SEL_V1..SEL_V4, SW_V1..SW_V4
#   PWR      3V3, 3V3_MOD   (both mapped above)
#   default  LED_STAT, LED_STAT_A
#   GND      pours + stitching on all four layers; no netclass width
#
# LED_STAT_A is the ballasted anode node between R_LED and LED_ST. A series
# resistor between a driver and an LED needs two nets and there is no way
# around it. Default class (0.25 mm) is correct at 1.3-2.2 mA.
#
# THREE CLASSES v1 CARRIES AND v2 DOES NOT — USB_D, QSPI, DVDD_1V1 — are gone
# with the bare chip. Their nets do not appear anywhere in this board's design.
