## 8. F-ECHO — the concrete instruction

**Run it after uploading `fab/bom.csv` and BEFORE paying.**

```
/usr/bin/python3 skills/jlcpcb-fab/scripts/bom_legibility_check.py \
  projects/crow-recorder-central-v2/07_releases/crow-recorder-central-v2-v1.6-2026-07-27/fab/bom.csv \
  --echo <jlc_resolved.csv>
```

**What to save.** From JLC's assembly UI, after the BOM is uploaded and matched,
export or copy out the **resolved / matched part table** — the one showing, per
line, the part JLC actually selected. Save it as CSV anywhere; the path goes in
`--echo`. The 47-line worklist to check it against is the release's own
`verification/bom_echo_gate.txt`.

**The parser is deliberately permissive about column names**, because *a gate
that rejects the evidence format is a gate that gets skipped*. It reads the
header case-insensitively and needs no exact schema:

- **"our" code** = any column whose name contains `lcsc` (and not `match`/`jlc`)
  holding a value shaped like an LCSC code.
- **"their" code** = any column whose name contains `match`, `jlc`, or
  `resolved`.
- an optional `Designator` / `Designators` column is used as a fallback key.
- Extra columns, extra rows, BOM markers and reordered columns are all fine.

**The one thing you must get right:** if the export has only a SINGLE code
column and it is named plainly (`LCSC`, `LCSC Part`), the tool reads it as *our*
code and cannot see a redirect. Either keep both columns, or **rename JLC's
resolved column to include the word `Matched`, `JLC` or `Resolved`.** Getting
this wrong fails LOUDLY (`OUR code does not appear in JLC's resolved table at
all`) rather than passing quietly — but it costs a round trip.

**Finding classes:**

| output | means | do |
|---|---|---|
| `F-ECHO <code> (<refs>) unchanged` | JLC resolved our exact code | nothing |
| `F-ECHO SUBSTITUTION <refs>: we specified X, JLC resolved Y` | **a redirect** | adjudicate BEFORE paying. For `U5` X=C82317 Y=C131025 → **ACCEPT** (§4). Anything else → verify MPN, brand, package and spec string against `02_parts/` before accepting |
| `F-ECHO <code>: OUR code does not appear in JLC's resolved table at all` | the line was DROPPED, or the export is not the one uploaded | stop. Either JLC silently dropped a line, or you saved the wrong table |
| `F-ECHO: not one of our codes was found … a zero denominator is a FAIL` | wrong file entirely | re-export |

Coverage prints as `N/47 coded rows echoed against <file>`. **Read the
denominator, not just the verdict** — F-ECHO passing on 3 of 47 rows is not a
clean bill.
