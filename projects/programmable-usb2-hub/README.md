# Programmable USB 2.0 hub

Four-port, self-powered USB 2.0 hub with 5 V / 3 A available at each
downstream USB-A receptacle. A USB-connected management controller provides
per-port power switching, physical D+/D- connection control, fault and power
telemetry, and a host utility that combines commanded state with the hub's
actual attach/enumeration state.

Status: commission complete; architecture and sourcing spike in progress.

Current release: none.

Build entry point: `bash 03_src/rebuild_all.sh` after the schematic and rules
stages are complete.
