# contract: 01_docs/learnings/

**Purpose** — per-stage harvest sources (canon M9): record what bit, why, and
how the next board avoids it. These are raw evidence for later skill/canon
harvest, not a second home for policy.

## Allowed

| Pattern | What |
|---|---|
| `<stage>.md` | one file per completed stage |
| `contracts.md` | this file |

Each issue records `what happened`, `root cause`, `avoid next time`, and
`candidate-canon`. A release requires a completed-stage reflection; an
explicit “nothing learned” entry is valid only after reflection.
