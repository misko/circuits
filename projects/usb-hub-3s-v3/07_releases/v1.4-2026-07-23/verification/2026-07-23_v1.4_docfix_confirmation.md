## Fix 1 — SW1 fallback-header shunt polarity (EXT13-4) → CONFIRMED + FIXED

- Source trace (source/usb_hub_3s_v2.tsx, identical bytes in both releases):
  `<chip name="SW1" ... connections={{ pin1: "net.GND", pin2: "net.ENKILL" }}`
  with the authoring comment `COM(2)=ENKILL, T1(1)=GND: slide to T1 grounds
  ENKILL -> buck-A off directly ... both bucks ON` (tsx lines ~303-316).
- power_tree.yaml `off_control`: grounding ENKILL drives BOTH LM5116 bucks to
  shutdown AND opens Q6 (Q7 inverter). E-INV asserts ENKILL == {U2.4, U11.4,
  SW1.2, Q7.1, R8.2, R17.2} — SW1 pin 2 (COM) is ON the ENKILL bus, pin 1 (T1)
  is GND.
- Therefore a shunt across COM-T1 connects ENKILL to GND = **OFF**; removing
  it lets ENKILL float up via R8/R17 = **ON**.
- v1.3 ORDER_README line 74 said: "COM-T1 shunted = ON; shunt removed = OFF" —
  REVERSED. v1.4 ORDER_README section 2 says: "COM-T1 shunted = OFF; shunt
  removed = ON" + continuity-verify gate Q6. CONFIRMED CORRECT.

## Fix 3 — tolerance-inclusive rail corners (EXT13-3) → CONFIRMED + FIXED

- BOM row 3 (identical both releases): `1.21kΩ,"R13,R4",...,C5126242`.
- Ledger decode (skills/jlcpcb-fab/references/lcsc_passives_ledger.yaml:150):
  C5126242 = **FRC0603F1211TS** = 1.21 k, FRC0603**F** series = **±1 %** —
  not 0.1 %. R12 = C2984354 (AR03BTCX4121) = ±0.1 % (ledger:149);
  R3 = C728591 (RT0603BRD073K92L) = ±0.1 % (ledger:142). Vref = 1.215 V ±1.5 %
  (LM5116 datasheet, as in power_tree.yaml).
- Recomputed corners, Vout = Vref(1 + Rtop/Rbot) (python3, this session):
  - 5VC nom = 1.215×(1+4.12/1.21) = **5.352 V**
  - 5VC min = 1.215×0.985×(1+4.12×0.999/(1.21×1.01)) = **5.2274 V**
  - 5VC max = 1.215×1.015×(1+4.12×1.001/(1.21×0.99)) = **5.4790 V**
  - 5VA nom **5.151 V**, min **5.032 V**, max **5.2729 V**
- Low corner: 5.227 − 4.63 (Pi UV) = **597 mV** vs the 440 mV IR budget
  (5 A × 88 mΩ) → **PASS, 157 mV slack** (E-MARGIN conclusion unchanged;
  power_tree.yaml's 5.272 V worst-low was the Vref-only corner — the release
  README now carries the tolerance-inclusive derivation; the gate math in
  power_tree.yaml is a next-rev doc sync item, its PASS verdict is unaffected).
- High corner: 5VC no-load static can reach **5.479 V**; USB-A 5VA top corner
  **5.273 V > the 5.25 V intended ceiling** (R4 ±1 %). Both now stated in the
  v1.4 ORDER_README table with measurement gates (no-load ≤5.45 V firm ceiling,
  overshoot capture). CONFIRMED the shipped table matches this derivation.
