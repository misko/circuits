# ARCHITECTURE — crow-array-central

Central synchronized recorder of the Crow Acoustic Localization Array
(commission: ../crow-array/01_docs/BRIEF.md, source sections 5/5A/4/8A).
One XU316 + two shared-clock PCM1865 ADCs expose six (of eight) analog
channels as a self-clocked asynchronous UAC2 device to a Raspberry Pi 5.
Eight RJ45 cable ports carry the CUSTOM (not-Ethernet) 5V/audio pinout to
the mic pods (sibling board: projects/crow-array-pod).

## Topology

```
                 8x RJ45 (RJHSE5384, J1..J8; J7/J8 DNP)   "NOT ETHERNET"
                 | per port: TPD2E2U06 ESD on AUDIO+/-
                 |           MINISMDC050F-2 PTC on +5V_AUDIO feed
                 |           MINISMDC050F-2 PTC on +5V_BEEP feed
                 |           1uF+1uF diff AC coupling -> RC -> PCM1865 VINnP/N
                 |           AO3400A low-side beeper switch (RC-slowed gate),
                 |           BEEP_RET kept as its OWN copper back to the FET
                 v
   ADC1 PCM1865 (ch1-4 = ports 1-4)      ADC2 PCM1865 (ch5-8 = ports 5-8)
        \  TDM DOUT (DATA1)                   /  TDM DOUT (DATA2)
         \  shared MCLK (NC7NZ34 buffered), BCLK, LRCK, RESET, I2C
          v                                  v
              XU316-1024-TQ128-I24  (app-PLL 24.576M MCLK master,
              TDM master, async UAC2)  + W25Q16JVSSIQ QSPI boot
              + FA-238 24MHz crystal + SHT40 I2C T/RH
          |
          v
   USB4105-GF-A-060 USB-C (device, USB-HS) + TPD4EUSB30DQAR ESD -> Pi 5

power: 5V barrel (GST25A05-P1J) -> PTC + TVS + reverse-P-FET -> 5V rail
  AP61102 buck #1 -> 3V3  (VDDIO, flash, buffer, PCM1865 DVDD/IOVDD, SHT40)
  AP61102 buck #2 -> 0V9  (XU316 core)
  TCR2LF18 (from 3V3)  -> 1V8  (XU316 support rail per ref design)
  XC6227C331 (from 5V) -> 3V3A (PCM1865 AVDD, quiet analog)
  sequencing copied from the XMOS multichannel audio platform manual
  (ADR-0003), implemented with EN/PG-style daisy chain.
```

## Channel / port map

| Port | RJ45 | ADC          | Channel | Rev-A |
|------|------|--------------|---------|-------|
| 1-4  | J1-J4| ADC1 VIN1-4  | 1-4     | populated |
| 5-6  | J5-J6| ADC2 VIN1-2  | 5-6     | populated |
| 7-8  | J7-J8| ADC2 VIN3-4  | 7-8     | jack DNP; channels reserved + injection taps |

Same-signal injection header J10 couples ONE test signal through per-leg
series resistors into ADC1's and ADC2's spare-channel input networks so
inter-chip skew is measurable (brief §5A); series resistors keep later
J7/J8 population legal.

## The port channel (8x repeated structure)

Generated by one `port_channel(n)` function in both the schematic and
board generators (commission requirement). Per port n:

- RJ45 pins 1/2 = AUDIO_P/N -> TPD2E2U06 (at jack) -> 1uF || 1uF coupling
  -> 49.9R + diff/CM RC -> PCM1865 VINxP/VINxN (internally biased).
- Pins 4,7 = +5V_AUDIO via shared-per-port PTC PF_nA; pins 5,8 = GND_AUDIO.
- Pin 3 = +5V_BEEP via PTC PF_nB; pin 6 = BEEP_RETn -> AO3400A drain;
  source -> GND star; gate <- XU316 GPIO via 1k series + 4.7nF to source
  (slowed edges, ADR-0005) + 100k pulldown (off during boot).
- TP on BEEP_RETn.

## Layout zones (audit invariants)

- North edge: RJ45 row + the entire beeper current path (feeds, FETs,
  returns). Beeper copper NEVER enters the analog band.
- Analog band (center-north): coupling networks + both PCM1865 + XC6227;
  continuous GND underneath (In1 plane, R-PLANE region check).
- Digital south-center: XU316, flash, crystal, buffer, USB-C at south edge
  (short controlled diff pair over continuous plane).
- Power west/south-west corner: entry, protection, both bucks; >= 25mm
  from either PCM1865 (audit proximity check).

## Stackup

4-layer JLC7628 (ADR-0001): F.Cu signal — In1.Cu solid GND — In2.Cu power
islands (3V3 / 0V9 / 5V / 3V3A) — B.Cu signal + GND pour.

## Firmware/bring-up posture

Board boots from QSPI; xSYS debug header carried; ORDER gated on the
commission's build sequence (pod field tests + USB firmware proof on the
XMOS eval board) — see ORDER_README of any release.
