### Checks that PASSED (measured, no defect)

- **XU316 EP thermal array (brief item 3):** the EP is a proper via-in-pad array — **16 through-hole vias (0.30 mm drill) in a 3.30 × 3.30 mm grid, all on GND**, inside the 4.7 mm EP. (My first pass counted board `PCB_VIA_T` objects and saw 0; the vias are modeled as footprint `pad "129"` PTHs — corrected.) Solid thermal + GND-reference path to In1/In4. Not a defect.
- **Switch-node geometry (brief item 1):** BK1_SW / BK2_SW are minimal F.Cu track only (len 4.8 mm, span 4.5 mm, 0.4 mm width, **no copper pour, 0 vias**) — small radiating area, well-controlled. SW→inductor 4.47 mm both. Only the input-cap distance (L2) is the loop concern.
- **Layer adjacency / stackup (brief item 2):** In1 GND 95% and In4 GND 95% are near-solid reference planes; F.Cu refs In1, B.Cu refs In4, In2 refs In1, In3 refs In4 — every signal layer has an adjacent GND plane. (The USB issue in L1 is broken *pair* coupling, not a missing plane — each leg still has a reference.)

### P1 detail

**L1 — USB-HS pair.** I summed per-layer track length by net. USB_DP routes 6.16 mm on F.Cu, **10.4 mm on B.Cu**, 4.66 mm on In2 through 4 vias (0.30 drill / 0.60 dia stubs). USB_DM routes 11.68 mm F.Cu + 10.47 mm In2 through 3 vias and **never enters B.Cu**. Because DP spends its majority length on B.Cu while DM does not, the two legs are on different layers for ~10 mm and cannot be a tightly-coupled 90 Ω pair over that stretch → intra-pair impedance discontinuity, common-mode conversion, and via-stub reflections at HS. Total-length match is fine (21.2 vs 22.2 mm = 0.93 mm), so skew is small, but the layer-hopping directly contradicts nets.yaml USB intent ("wave 0, F.Cu only, no vias") and the ADR claim of a short adjacent pair (it is 15.3 mm through the D10 ESD array). USB 2.0 HS is robust enough that it will likely still enumerate, hence P1 not P0 — but it is the primary off-board data path and should be re-routed F.Cu-only next rev.

**L2 — buck input loop.** Nearest-pad measurement: U10 VIN→C10 = 5.57 mm, U11 VIN→C13 = 6.14 mm, with no smaller HF ceramic closer than the 4u7 bulk. For a ~1.5 A synchronous AP61102 the input cap wants to be <2 mm from VIN/GND; at ~6 mm the hot-loop inductance raises input ripple and radiated EMI. Both bucks share this placement pattern.

**L3 — long analog inputs.** AIN_P4 net = 106.3 mm of routed copper (19 segments, F.Cu+In2) against a 1.5 mm partner (AIN_N4), and AIN_P8 = 69.5 mm vs 1.4 mm. A ~100 mm single-ended-effective analog ADC input on a 176 mm board is a sizeable noise/crosstalk antenna in exactly the corridor the brief calls out. (Topology note: AIN_N4/N8 have no ADC-side resistor in their pad set, so these may be pseudo-differential inputs with a local reference — which makes the long P leg's single-ended pickup worse, not better. Flagged on the measured length regardless.)

### VERDICT

**ORDER** — no P0: the release gate is clean (0 violations / 0 parity), the XU316 EP has a real 16-via/3.3 mm thermal array, In1/In4 GND planes are 95% solid with 414 stitch vias, switch nodes are tight track-only, and all geometry is at-or-above the JLC small-via floor; the sole deciding risks (USB pair layer-split L1, buck input-cap distance L2, 106 mm analog input L3) are P1 next-rev/order-note improvements, not order-blockers.
