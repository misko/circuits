# net_aliases.txt — TSNAME CANONICAL, one per line. `#` starts a comment;
# `=` and `->` are also accepted as separators. Auto-discovered by the
# converter (circuit_json_to_kicad_sch.py) next to build/.
#
# WHY IT EXISTS AT ALL: tscircuit's `net.` selector cannot author a name
# starting with a digit, so a digit-leading rail is authored with an
# author-prefix `N`. The converter's canon_net then strips a single leading
# `N` THAT GUARDS A DIGIT (N5V -> 5V, N3V3 -> 3V3) and leaves a leading N
# followed by a non-digit alone (NRST, NC, NRESET).
#
# THIS BOARD HAS EXACTLY ONE DIGIT-LEADING RAIL AND IT IS WRITTEN OUT BELOW
# RATHER THAN LEFT TO THE CONVENTION. The convention would handle it, and the
# line is still here on purpose: 03_src/rules/nets.yaml keys its netclasses on
# the CANONICAL names, and on this board a netclass miss is not cosmetic — the
# PWR class is `min_width: 0.4mm` for IR drop and robustness, and a 3V3 that
# fell to the default 0.25 mm class would be graded by A-AMP as a signal net.
# An explicit mapping cannot be silently wrong the way an assumed one can.
N3V3 3V3
