# KiCad 10.0.4 package-model subset

These are unmodified package models from KiCad's official
[`kicad-packages3D`](https://gitlab.com/kicad/libraries/kicad-packages3D)
repository, pinned to tag `10.0.4`. Only the eight files needed to make this
board's fitted population renderer-complete are vendored; the footprints
remain the stock KiCad footprints.

Upstream files use this immutable URL form:

`https://gitlab.com/kicad/libraries/kicad-packages3D/-/raw/10.0.4/<path>`

The upstream licence is retained as `LICENSE.md` in this directory. Run
`sha256sum -c SHA256SUMS` here to verify the downloaded subset.
