# USB controlled debug hub v1

Four-port self-powered USB 2.0 debug hub with independent per-port VBUS and
D+/D- control through an onboard USB management function.

Status: commission and exact-part sourcing in progress. No release exists and
the board is not ready to order.

Firmware is outside scope. See `01_docs/BRIEF.md` for the commission and
`01_docs/ARCHITECTURE.md` for the locked topology.
